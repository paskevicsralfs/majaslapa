Projekta Apraksts

Entuziastu Volejbola Otrās Vīriešu Līgas mājaslapa ir tīmekļa lietotne, kasparedzēta čempionāta informācijas publicēšanai un brīvo aģentu piesaistei.

Mājaslapa nodrošina:

  • Aktuālo komandu kopvērtējuma tabulu
  • Spēlētāju sarakstu ar filtrēšanu
  • Spēļu grafiku ar rezultātiem
  • Brīvo aģentu reģistrācijas sistēmu
  • Spēlētāju pārvaldības sistēmu (CRUD)

Datubāzes Struktūra

Datubāze sastāv no 4 savstarpēji saistītām tabulām:

Tabula Apraksts Ārējās Atsauces
teams Komandu dati -
players Spēlētāju dati teams.id
games Spēļu dati teams.id (x2)
teams
id INTEGER PK
name TEXT
played INTEGER
won INTEGER
lost INTEGER
points INTEGER
sets_won INTEGER
sets_lost INTEGER
players
id INTEGER PK
first_name TEXT
last_name TEXT
position TEXT
team_id INTEGER FK
phone TEXT
created_at TIMESTAMP
games
id INTEGER PK
home_team_id INTEGER FK
away_team_id INTEGER FK
date TEXT
time TEXT
location TEXT
home_score INTEGER
away_score INTEGER
status TEXT

Tabulu Sakarības:

  • players.team_id → teams.id (Daudzi pret vienu)
  • games.home_team_id → teams.id (Daudzi pret vienu)
  • games.away_team_id → teams.id (Daudzi pret vienu)
